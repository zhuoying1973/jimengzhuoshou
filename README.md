# 🎬 即梦AI 智能提示词提取与无水印下载助手 (JimengAI Helper)

即梦AI 助手是一款专为 **即梦 AI (Jimeng AI)** 创作者打造的轻量级、便携式本地辅助工具。它专注于解决即梦平台作品“提示词提取困难”以及“生成视频/图片防盗链限制、下载带水印”的痛点。

项目采用 **纯前端单页面 (HTML/CSS/Vue3) + 轻量化 Python (Flask)** 架构设计，界面采用前沿的**暗黑磨砂玻璃 (Glassmorphism) 与发光霓虹**美学，带给创作者最极致的操作体验。

---

## ✨ 核心功能
* **🚀 智能提取与自动建档**：直接粘贴即梦 APP 或网页版分享出来的作品链接，一键极速抓取该作品的封面、无水印视频/图片直链以及作者的原始长提示词。解析过的创作者会被自动记录在名录中，建立本地画廊，点击即可直接流畅检索。
* **🤖 AI 大模型智能反推 (通义千问-VL-Max)**：若创作者在发布作品时抹去了原始提示词，助手集成阿里通义千问多模态大模型，可一键对作品封面进行高精度视觉分析，反向重构具有极强画面感、运镜描述的专业提示词，并支持一键复制。
* **📥 穿透防盗链极速下载**：通过内置的中转代理服务，100% 穿透字节跳动官方 CDN 防盗链（403 Forbidden 拦截）保护，在软件内实现秒播视频、一键保存无水印原片到本地。
* **📱 绿色便携，开箱即用**：项目内置了微型绿色 Python 运行环境，**支持整包文件夹一键拷贝至任何 Windows 电脑**，双击即可无痛运行，无需配置任何环境变量，且绝对不会被 360 等杀毒软件误杀。

## 🚀 运行与便携使用指引

### 1. 本地双击启动
1. 拷贝 `JimengHelper` 文件夹到您电脑上的任意位置（支持 U 盘随身携带）。
2. 在文件夹根目录下，直接双击 **`run.bat`**。
3. 助手会自动查杀端口冲突、拉起 Flask 服务，并自动为您打开默认浏览器进入助手主页 `http://127.0.0.1:5000`。

### 2. 局域网跨端浏览 (手机端)
1. 确保您的电脑与手机连接在同一个 Wi-Fi（局域网）下。
2. 启动助手时，黑色的控制台窗口会自动为您打印本机的局域网 IP：
   ```text
   局域网(手机端)访问地址: http://192.168.x.x:5000
   ```
3. 在您的手机浏览器上直接访问该地址，即可同步使用助手的全部检索、下载与大模型反推功能！
